# Customer review screenshots

The gallery automatically loads the approved screenshots in this folder using these filename groups:

- `TESTIMONI CUSTOMER 1.jpeg` through `TESTIMONI CUSTOMER 46.jpeg`
- `TESTIMONI MAKE UP 1.jpeg` through `TESTIMONI MAKE UP 3.jpeg`
- `TESTIMONI TAWAK 1.jpeg` through `TESTIMONI TAWAK 3.jpeg`

If the number or file extension changes, update `getReviewScreenshots()` in `assets/js/main.js`.

Before publishing, redact phone numbers, profile photographs, email addresses, and other private information unless the customer has explicitly approved their display.

Recommended image preparation:

- Use portrait screenshots.
- Crop away unused areas.
- Keep text readable.
- Aim for less than 500 KB per image for faster loading.
